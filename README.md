# Kino XII

Cinema network ticket booking app — Redberry Bootcamp XII assignment.

Browse films, filter sessions across four venues, pick seats from a live hall map and buy tickets.

## Stack

React 19 · JavaScript · Vite · Tailwind CSS v4 · React Router · TanStack Query · React Hook Form + Zod

## Running it

```bash
npm install
npm run dev
```

Backend is provided by Redberry: `https://api.kinoxii.redberryinternship.ge/api`
